PHP + MySQL Project

Adoption Pawtal

A modern pet adoption platform built for finding loving homes for animals in need. This project lets users browse available pets, view details, and submit adoption applications, while admins manage listings, statuses, and notifications from a secure dashboard.

View GitHub Repo Read the README
GitHub Pages is a static hosting service, so this page serves as a project landing page. The actual pet adoption app runs locally using PHP and MySQL on your machine.

What the project includes

  • Browse pets and filter by type, size, and sex
  • View detailed information for each animal
  • Submit adoption applications from the public site
  • Manage pets and applications from the admin dashboard
  • Track adoption status and send email notifications
  • Upload pet images and manage listings in the database
